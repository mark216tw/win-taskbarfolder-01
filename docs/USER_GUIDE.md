# 使用指南

本文件說明 TaskbarFolders 的安裝、介面操作、釘選流程與常見問題。若想了解內部實作，請參閱[系統架構與技術文件](ARCHITECTURE.md)。

## 1. 安裝

TaskbarFolders 以可攜式 zip 發佈，不提供安裝程式。

1. 開啟 [Releases](https://github.com/mark216tw/TaskbarFolders/releases) 頁面。
2. 依裝置架構下載 `TaskbarFolders-<版本>-win-x64.zip` 或 `TaskbarFolders-<版本>-win-arm64.zip`。
3. 解壓縮到固定資料夾，例如 `C:\Apps\TaskbarFolders`。
4. 安裝 [.NET 10 Desktop Runtime](https://dotnet.microsoft.com/download/dotnet/10.0)（zip 為非 Self-Contained，需另外安裝執行階段）。
5. 執行 `TaskbarFolders.exe`。

### 如何確認架構

- 設定 → 系統 → 關於，查看「系統類型」。
- 顯示「64 位元作業系統，x64 處理器」→ 使用 x64。
- 顯示「ARM 架構處理器」→ 使用 arm64。

### SmartScreen 提示

執行檔未進行程式碼簽章，首次執行可能出現「Windows 已保護您的電腦」。請點「更多資訊」→「仍要執行」。若您自行從原始碼建置，同樣會看到此提示。

## 2. 介面概覽

主視窗（TaskbarFolders 設定）分為三區：

| 區域 | 內容 |
| --- | --- |
| 左側分類清單 | 所有分類，可拖曳排序；下方有「新增分類」 |
| 中間分類設定 | 分類名稱、同一列的分類圖示與分類主題按鈕、刪除分類 |
| 右側項目清單 | 該分類的應用程式，可加入、移除、重新命名、上下移動 |

視窗底部有狀態列，顯示就緒、掃描中、已儲存或錯誤訊息；成功訊息會自動消失。

## 3. 建立與管理分類

### 新增分類

1. 按左側「新增分類」。
2. 輸入分類名稱（預設名稱為「新分類」）。
3. 未指定圖示時會自動套用內建「資料夾」圖示。

### 選擇分類圖示

1. 點擊名稱下方、分類主題按鈕左側的圖示按鈕。
2. 在彈出的選單中選擇 60 個內建圖示之一。
3. 選取後選單會自動收起。

內建圖示分為工作、開發、影音、生活、遊戲、軟體 6 個主題，每個主題 10 個圖示（共 60 個）；面板會將主題標題與圖示顯示在同一列，內容較多時可捲動。圖示選單內的圖示統一以深灰底色預覽。

### 選擇分類主題

點擊圖示按鈕右側的分類主題色塊，會彈出色塊選單；選單只顯示顏色區塊，不顯示名稱。清單包含「無」與 17 種顏色：

- 無（空白加斜線，跟隨全域淺色／深色主題）
- 黃色護眼、海洋藍、森林綠、薰衣草紫、暖陽橙
- 玫瑰紅、櫻花粉、湖水綠、天空青、靛藍、咖啡棕、石墨灰
- 青檸綠、深海藍、洋紅、珊瑚橘、酒紅

選取後選單會自動收起；分類主題會套用於該分類的飛出面板與分類圖示底色，不影響主編輯視窗；同一個主題會依目前淺色／深色模式自動選用對應色盤。分類主題為「無」時，圖示底色為深灰。

### 調整分類順序

在左側清單按住分類拖曳即可排序。拖曳時會顯示浮動縮影與插入位置指示線，放開後有淡入縮放動畫。分類順序會影響：

- 清單顯示順序
- 產生捷徑時的處理順序
- 同名分類的捷徑檔名序號

### 刪除分類

選取分類後按「刪除分類」，確認後移除。分類內的應用程式項目只會從設定中移除，不會刪除磁碟上的原始檔案或已釘選的工作列捷徑。

## 4. 加入應用程式

### 從開始功能表匯入

1. 選取分類。
2. 按「從開始功能表匯入」。
3. 在對話框搜尋應用程式。
4. 按住 Ctrl 或 Shift 多選，或使用「全選」／「清除選取」。
5. 按「確定」加入。

掃描範圍包含使用者與全機器的開始功能表，以及 `shell:AppsFolder` 中的 Microsoft Store / UWP 應用程式。掃描結果會快取 60 秒，短時間內重複開啟不需要重新掃描。

### 加入檔案或捷徑

1. 按「加入檔案」。
2. 選擇 `.exe`、`.lnk`、`.url`、`.bat`、`.cmd`、`.appref-ms` 或所有檔案。
3. 檔案會以檔名加入目前分類。

### 加入網址

1. 按「加入網址」。
2. 輸入完整網址，例如 `https://example.com`。
3. 確定後會建立網頁項目，日後以預設瀏覽器開啟。

### 調整與移除項目

- 選取項目後使用「上移」／「下移」調整順序。
- 按「重新命名」修改顯示名稱（不影響原始檔案）。
- 按「移除」從分類移除，不會刪除原始檔案。

## 5. 儲存與釘選

### 儲存分類設定

主畫面的「儲存」只處理分類，按「儲存」後會：

1. 將分類寫入 `%AppData%\TaskbarFolders\config.json`，並保留上一版為 `config.json.bak`。
2. 同步分類捷徑：只重建有變更的分類，未變更者直接沿用。
3. 更新捷徑圖示檔。
4. 清理已刪除分類留下的 `.lnk`、`.ico`、`.sig`。

沒有未儲存分類變更時，「儲存」按鈕會停用。關閉視窗時若有未儲存分類變更，會先詢問。顯示模式不在主畫面儲存，請至設定視窗設定。

### 產生釘選捷徑

1. 按「產生釘選捷徑」。
2. 在釘選精靈中按「開啟資料夾」，檔案總管會選取剛建立的捷徑。
3. 對捷徑按右鍵 →「顯示更多選項」→「釘選到工作列」。
4. 回到工作列點擊該分類圖示，即可展開飛出面板。

> Windows 11 基於安全性理由，不允許程式自動把項目釘到工作列；這一步一定要由使用者手動完成。Windows 更新後若釘選消失，請重新執行上述步驟。

### 捷徑命名規則

- 捷徑檔名使用分類名稱，例如「開發工具.lnk」。
- 檔名會移除 Windows 不允許的字元，並限制長度為 80 個字元。
- 同名分類會加上序號，例如「工具 (2).lnk」。
- 重新命名分類會產生新檔名的捷徑；工作列上已釘選的舊捷徑仍可運作，但建議重新產生並重新釘選。

## 6. 飛出面板操作

| 操作 | 結果 |
| --- | --- |
| 點擊工作列上的分類圖示 | 在工作列上方展開面板 |
| 滑鼠左鍵點擊項目 | 啟動該應用程式並關閉面板 |
| 在項目上按滑鼠右鍵 | 開啟選單，可選擇「編輯顯示名稱」 |
| 方向鍵 | 移動選取項目（左右移動一格，上下移動一列，一列 5 個） |
| Enter | 啟動選取項目 |
| Esc | 關閉面板 |
| 點擊面板外任意處 | 關閉面板 |
| 點擊右上角「✕」 | 關閉面板 |

- 右鍵選「編輯顯示名稱」後輸入新名稱，會立即寫入設定；只影響面板顯示名稱，不影響原始檔案或捷徑。
- 若主編輯器同時開著且有未儲存變更，之後在主編輯器儲存可能覆蓋飛出面板的改名；建議先關閉主編輯器或先儲存。
- 面板寬度固定 500 DIP，一列顯示 5 個圖示。
- 高度依目錄螢幕上工作列以外的可用空間自動調整，最少 150 DIP。
- 面板不顯示垂直捲軸；內容過多時仍可使用滑鼠滾輪或鍵盤移動選取。
- 飛出面板不會常駐，也不會建立系統匣圖示；每次點擊都是獨立啟動的程序。

## 7. 設定

按主視窗右上角「⋯」開啟設定視窗，可調整「顯示模式」：

- 跟隨系統
- 淺色
- 深色

選好後按「儲存」寫入設定。設定視窗的「儲存」只儲存顯示模式，不會寫入或覆蓋分類，也不會重建捷徑；沒有變更顯示模式時，「儲存」按鈕會停用。未按「儲存」就關閉設定視窗時，顯示模式會還原為上次儲存的值。儲存按鈕背景會使用目前選取分類的主題色；分類主題為「無」時使用預設強調色。

### 關於

設定視窗下方的「關於」區塊顯示版本、檔案版本、授權與著作權，版本資訊由程式組件屬性讀取。所有設定與資料僅儲存在本機，不會收集或上傳任何個人資料。

### 匯出與匯入分類設定

設定視窗下方的「分類設定」可備份或還原所有分類：

1. 按「匯出分類設定」，選擇儲存位置。匯出的 JSON 包含所有分類、分類圖示、分類主題與項目，但不含顯示模式。
2. 按「匯入分類設定」並選擇先前匯出的 JSON。
3. 確認後會直接覆蓋目前所有分類，立即寫入 `config.json` 並同步捷徑。

> 匯入不會合併資料，也不會保留匯入前的分類。若需要保留目前設定，請先匯出備份。

## 8. 資料位置與備份

| 內容 | 路徑 |
| --- | --- |
| 設定 | `%AppData%\TaskbarFolders\config.json` |
| 設定備份 | `%AppData%\TaskbarFolders\config.json.bak` |
| 視窗狀態 | `%AppData%\TaskbarFolders\window.json` |
| 釘選捷徑 | `%AppData%\TaskbarFolders\Shortcuts\` |
| 圖示快取 | `%LocalAppData%\TaskbarFolders\IconCache\` |
| 記錄檔 | `%LocalAppData%\TaskbarFolders\Logs\taskbarfolders.log` |

### 備份與還原

- 備份：複製整個 `%AppData%\TaskbarFolders` 資料夾，或在設定頁使用「匯出分類設定」保存分類 JSON。
- 還原：關閉 TaskbarFolders 後，以備份覆蓋同一資料夾，再重新啟動；或從設定頁匯入分類 JSON。
- 若 `config.json` 損毀，程式會自動嘗試讀取 `config.json.bak`；兩者都失敗才會回到預設設定。

### 清理

- 圖示快取超過 30 天未使用會自動清除，每天最多執行一次。
- 記錄檔超過 1 MB 會輪替為 `taskbarfolders.log.1`。
- 若要完全移除程式：刪除程式資料夾，並視需要刪除 `%AppData%\TaskbarFolders` 與 `%LocalAppData%\TaskbarFolders`；最後手動取消釘選工作列上的分類捷徑。

## 9. 疑難排解

### 點擊工作列圖示沒有反應

- 確認該圖示是 TaskbarFolders 產生的分類捷徑，而不是舊的捷徑。
- 重新按「儲存」或「產生釘選捷徑」，再重新釘選。
- 若最近重新命名分類，請以新捷徑重新釘選。

### 飛出面板出現在錯誤的螢幕

程式會優先使用目前前景視窗所在的螢幕；若前景是本程式，才退回游標位置。若仍不正確，請確認 Windows 顯示設定中的螢幕排列。

### 圖示空白或錯誤

- 關閉程式後刪除 `%LocalAppData%\TaskbarFolders\IconCache\`，再重新啟動。
- UWP 應用程式圖示需要 `shell:AppsFolder` 正常運作；若系統圖示快取異常，可重新登入 Windows。

### UWP / Store 應用程式無法啟動

- 確認應用程式仍已安裝。
- 嘗試從開始功能表直接啟動一次，讓 Windows 重建應用程式註冊。

### 程式無法啟動且沒有畫面

查看 `%LocalAppData%\TaskbarFolders\Logs\taskbarfolders.log`，通常會記錄啟動失敗原因。回報問題時請附上記錄檔內容（請先確認不含個人路徑等敏感資訊）。

### 非 Self-Contained 版本提示缺少執行階段

安裝 [.NET 10 Desktop Runtime](https://dotnet.microsoft.com/download/dotnet/10.0)（x64 或 arm64 需與程式版本一致）。

## 10. 隱私

TaskbarFolders 只會：

- 讀取開始功能表與 Store 應用程式資訊。
- 讀取您選擇加入的檔案、捷徑與網址。
- 寫入自己的設定、捷徑、圖示快取與記錄檔。

程式不會上傳任何資料、不收集遙測、不要求系統管理員權限、不連線到網際網路。
